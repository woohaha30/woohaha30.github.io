# 아이폰(짝꿍 폰)에 설치하는 법 - PWA 방식

아이폰은 APK처럼 파일 하나 보내서 설치가 안 되고, Xcode + 맥 + (경우에 따라) 애플 개발자 계정이 필요해서
안드로이드보다 훨씬 번거로워요. 대신 **"홈 화면에 추가"** 방식이면 지금 있는 파일 그대로, 별도 앱스토어 등록 없이
아이콘 눌러서 거의 앱처럼 쓸 수 있어요.

## 1. 어딘가에 호스팅하기
index.html이랑 apple-touch-icon.png를 같은 폴더에 두고 웹에서 접근 가능하게 올려야 해요.
만돌님이 이미 갖고 계신 woohaha30.github.io GitHub Pages를 쓰면 제일 간단해요.

예:
```
woohaha30.github.io 저장소에 turtle 폴더 만들고
- turtle/index.html
- turtle/apple-touch-icon.png
두 파일 넣고 git push
```
그러면 https://woohaha30.github.io/turtle/ 로 접속 가능해져요.

(GitHub 안 쓰고 싶으면 Netlify Drop(app.netlify.com/drop)에 폴더째 드래그해도 몇 초 만에 링크 생김 - 로그인도 필요 없어요.)

## 2. 짝꿍 아이폰에서 설치
1. 그 링크를 아이폰 **Safari**로 열기 (크롬 아니고 꼭 Safari여야 함)
2. 하단 공유 버튼(네모+화살표) 탭
3. "홈 화면에 추가" 선택
4. 완료하면 홈 화면에 거북이 아이콘 생김 - 눌러서 실행하면 주소창 없이 앱처럼 나옴

## 참고
- 데이터(승천 횟수, 누적 개수)는 아이폰 로컬에 저장되니까 안드로이드 쪽 기록이랑은 공유되지 않아요. 각자 처음부터 시작.
- 나중에 "진짜" 앱스토어 앱으로 만들고 싶으면 맥+Xcode+애플 개발자 계정(연 99달러)이 필요해서, 지금은 이 방법이 제일 현실적이에요.
